# Mythos.Guide

## How to run

The app has not been built yet. A simple local run command will be added after the database setup step.

## Where it is published

Nowhere. Version 1 stays on this computer.

## What is done

- Git save points are set up.
- Private environment files are ignored by Git.
- The project requirements are saved in `AGENTS.md`.
- Database setup is waiting for the user to enter their MongoDB URL in `.env.local` and say "Done".

## What is next

1. After "Done", check the MongoDB connection privately, using the database in the URL.
2. Build a simple god-name search that returns a description, using sample data and serverless functions in `/api`.
3. Run it locally, open it in a browser, check the search, and make a save point.

Browsing, games, stories, and experiences of the gods' lives are future work.
